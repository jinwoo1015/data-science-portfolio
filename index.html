03 / Projects

Selected projects.

Presented at SUnMaRC

College Football Retention Churn Analysis

An XGBoost pipeline that predicts transfer portal entries from physical tracking data. SMOTE and stratified 5 fold cross validation handle the class imbalance, and forward feature selection isolates the indicators that drive the prediction. A Plotly and Streamlit dashboard delivers the results.

  • XGBoost
  • SMOTE
  • Plotly

Computer vision

Play Classification from Broadcast Video

An automated pipeline that classifies collegiate football plays as pass, run or sack straight from broadcast video. YOLOv8 detects players, biomechanical features are engineered from joint coordinates, and a Random Forest is validated with leave one out cross validation to prevent data leakage.

  • Python
  • YOLOv8
  • Random Forest
  • LOOCV
